# Sick Leave, Big Win!

A public, mobile-friendly satirical game show about sick-leave and return-to-work paperwork. Spin an eight-segment wheel, complete two fictional forms, and win bureaucracy points.

The satire targets bureaucracy, not people with health conditions. Scenarios use conditions that are often not outwardly visible: migraine, IBS flare-up, acid reflux, insomnia, tension headache, vertigo, period pain and anxiety flare-up. Individual experiences vary.

No real submissions, analytics, health-data collection, storage or backend. Use fictional names. Optional synthesised audio, reduced-motion support, keyboard-accessible forms and responsive layout included.

## Play

https://sickness-generator.petermg397303.chatgpt.site

## Run locally

Serve `dist/` with any static web server, for example `python3 -m http.server 8080 --directory dist`.

## Files

- `dist/index.html`: page structure
- `dist/style.css`: game-show theme
- `dist/game.js`: wheel, forms and scoring

The wheel also exposes a feature-detected browser WebMCP tool when supported.
